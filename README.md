# **Sweden Weather Visualization Project**  

This project provides a clear and open-source platform to display **daily weather data** for several locations in Sweden, including major cities and places I have personally visited. It focuses on four key weather variables across **nine weather stations**:  

- **Maximum temperature (°C)**  
- **Minimum temperature (°C)**  
- **Average temperature (°C)**  
- **Precipitation (mm)**  

The data is sourced from **CSV files updated daily**, ensuring the website remains a reliable and up-to-date resource for users interested in recent weather trends.  

👉 **Check it out here:** 
[Är det varmt just nu?](https://pablo-ferro.github.io/SwedishWeather/)

---

## **Key Features**  

### **1. Weather Stations Coverage**  
The website covers **nine important weather stations** in Sweden:  
- Stockholm-Observatoriekullen A  
- Stockholm-Arlanda Flygplats  
- Uppsala Flygplats  
- Västerås  
- Göteborg A  
- Malmö A  
- Umeå Flygplats  
- Kiruna Flygplats  
- Luleå-Kallax Flygplats  

### **2. Interactive Map (Leaflet Integration)**  
- Stations are plotted on an **interactive map** with **color-coded circular markers** (warmer = red, colder = blue).  
- Users can click on markers to see station details.  

### **3. Responsive Data Table**  
- A **sortable table** below the map displays all weather data, allowing easy comparison across stations.  

### **4. Precipitation Visualization**  
- Precipitation levels are shown as **scaled blue circles** (larger = more rainfall).  
- **Tooltips** provide exact values when hovering.  

### **5. Open & User-Friendly Design**  
- Built with transparency in mind—**raw data is openly accessible**.  
- Mobile-friendly and easy to navigate.  

---

## **Project Goal**  
The goal of **"Is it hot in Sweden today?"** is to provide an **open, transparent, and user-friendly** source of weather data, making it easy for the public to access and understand recent weather trends.
